# Distributed Oceanographic Data Analytics

## Marine Ecosystem Health Assessment

Interactive Streamlit dashboard for the project:

**Distributed Oceanographic Data Analytics for Marine Ecosystem Health Assessment**

### Technologies

- Python
- Streamlit
- PySpark
- Hadoop HDFS
- Scikit-learn
- Random Forest
- XGBoost
- LightGBM
- PCA
- K-Means
- Plotly
- SHAP

### Dashboard

The dashboard provides:

- Ocean Conditions
- Environmental Anomaly Analysis
- ML Oceanographic Regimes
- Geographic Analysis
- MEHI & Ecosystem Health
- Data Explorer
- Marine Environment Suitability Predictor
- Suitability Model Comparison
- Model Explainability
- Geographic Suitability
- Year-wise Suitability
- Depth-wise Suitability
- ML Suitability vs MEHI
- Download Center
- Methodology

### Suitability Classification

The project-defined analytical classes are:

- Not Suitable
- Moderate
- Suitable

The classification is based on standardized environmental anomaly
thresholds and should not be interpreted as biological ground truth.

### Deployment

This application is designed to be deployed using Streamlit Community Cloud.
